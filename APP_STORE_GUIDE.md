# Apple App Store

Who Got Who now has a Capacitor iOS project in `ios/`.
See [IOS_RELEASE.md](IOS_RELEASE.md) for the current build, signing and testing instructions.
The GitHub Actions workflow builds on a cloud Mac, so a local Mac is not required.
Android continues to use the existing Trusted Web Activity.

An App Store entry, signed build, device tests, screenshots and completed store
metadata are required before submission. Registration or a successful build does
not mean Apple has approved or published the app.
